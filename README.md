# Australian Car Crash Data Analysis - Power BI

## Project Overview
This project analyzes vehicular crash data in Australia to identify key trends, risk factors, and geographical hotspots. The goal of this dashboard is to transform raw data into actionable insights, demonstrating skills in data curation and statistical reporting.

## Tools Used
* **Power BI:** Data visualization, interactive dashboards, and reporting.
* **Power Query / DAX:** Data cleaning, transformation, and statistical metric calculations.

## Key Analytical Processes (ETL & BI)
1. **Data Curation:** Extracted and cleaned datasets of traffic incidents, handling missing values and normalizing geographical data.
2. **Data Modeling:** Established relationships between multiple data tables to allow seamless cross-filtering.
3. **Insights Generation:** Designed interactive visuals to highlight high-risk timeframes, demographic impacts, and severity metrics.
